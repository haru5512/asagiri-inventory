# 商品登録フォーム（PC管理画面）

## 概要

PC管理画面（inventory.html）の現在在庫タブに「新規登録」ボタンを追加し、モーダルで商品登録フォームを表示する。

## 配置

- 現在在庫タブ内、フィルタ行の横に「新規登録」ボタンを設置
- クリックでモーダル（オーバーレイ）を表示

## フォーム項目

| 項目 | 必須 | 入力方法 | デフォルト | 備考 |
|------|------|----------|-----------|------|
| 品目ID | 自動 | - | GAS側で自動採番 | IT001, IT002... |
| 品名 | 必須 | テキスト | - | |
| バーコード | 任意 | テキスト | - | JAN or 自社QR |
| 大カテゴリ | 必須 | ドロップダウン | - | 原料/加工品/備品/消耗品/完成品 |
| 中カテゴリ | 任意 | テキスト | - | 自由入力 |
| 単位 | 必須 | ドロップダウン | - | 個/kg/本/箱/袋 等 |
| 標準単価 | 任意 | 数値 | 0 | |
| 販売単価 | 任意 | 数値 | 0 | |
| ロット管理 | - | チェックボックス | OFF | |
| 賞味期限管理 | - | チェックボックス | OFF | |
| 税率 | 必須 | ドロップダウン | 8% | 8%/10% |
| 閾値 | 任意 | 数値 | - | 在庫アラート用 |
| 主場所ID | 任意 | ドロップダウン | - | M_場所から取得 |
| 有効 | 自動 | - | TRUE | |

## ボタン構成

- **登録して閉じる** - M_品目に登録後、モーダルを閉じて一覧に戻る
- **登録して続けて入力** - 登録後、フォームをクリアして次の商品入力へ
- **キャンセル** - 入力を破棄してモーダルを閉じる

## ロット番号の自動採番

入庫時のロット番号はGAS側で自動生成する。

- 形式: `L-YYYYMMDD-NNN`（日付 + 連番）
- 現場は入庫時に賞味期限だけ入力すればよい
- ロット番号の概念を現場が意識する必要なし

## GAS側に必要な新規API

### registerItem

M_品目シートに新規行を追加する。

- パラメータ: gmail, password, 品名, バーコード, 大カテゴリ, 中カテゴリ, 単位, 標準単価, 販売単価, ロット管理, 賞味期限管理, 税率, 閾値, 主場所ID
- 処理: 品目IDを自動採番（既存最大ID + 1）、有効=TRUE で行追加
- レスポンス: `{ success: true, data: { 品目ID: "IT003" } }`

## ファイル変更

- `inventory.html` - モーダルHTML追加
- `inventory.js` - モーダル表示/非表示、フォーム送信、バリデーション、連続入力
- `inventory.css` - モーダルスタイル

## 場所一覧の取得

主場所IDドロップダウン用に、M_場所のデータが必要。既存の getLocations API を使用する（PWA側と共通）。
