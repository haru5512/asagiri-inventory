# 棚卸UX改善 設計書

## 背景

現在の棚卸フローには以下の課題がある：
- PWAを閉じると進行中セッションに復帰できない（セッションIDがメモリのみ）
- 棚卸中に「あと何品残っているか」が分からない
- 未カウント品を現場で確認する手段がない
- サマリー画面は件数のみで差異の詳細が見えない
- PC管理画面で確定済み棚卸の印刷ができない

## 実装する機能

### 1. セッション再開（PWA）

**動作:**
- PWA棚卸開始画面で、GAS APIを呼んで自分の「進行中」セッションを検索
- 見つかった場合: 「進行中のセッションがあります（ST-XXXXXXXX-XXX）。再開しますか？」と表示
- 「再開」→ stSessionIdを復元してスキャン画面へ
- 「新規開始」→ 通常通り新セッション作成（旧セッションは進行中のまま残る）
- 見つからない場合: 通常通り新規開始画面

**GAS API:**
- 新規: `getMyActiveSession` — gmailでT_棚卸セッションを検索、ステータス「進行中」のセッションを返す
- 戻り値: `{ sessionId, startedAt, countedNum }` or `null`
- `countedNum` はT_棚卸明細から同セッションの備考!='未カウント'の件数を取得

**PWA変更:**
- `goToStocktakeStart()`: 開始画面表示前に `getMyActiveSession` を呼ぶ
- 開始画面に「再開」ボタンを条件表示
- `stSessionId` と `stCountedNum` を復元してスキャン画面へ遷移

### 2. 進捗表示（PWA）

**動作:**
- スキャン画面ヘッダー: 「棚卸中 (5/42品)」— カウント済み / 全品目数
- 全品目数 = 帳簿在庫>0の品目数（`getMyActiveSession` や `getStocktakeSummary` で取得）

**実装:**
- `getMyActiveSession` の戻り値に `totalItems`（帳簿在庫>0の品目数）を追加
- `startStocktake` の戻り値にも `totalItems` を追加
- PWA側で `stTotalItems` 変数を保持
- ヘッダー表示: `'棚卸中 (' + stCountedNum + '/' + stTotalItems + '品)'`

### 3. 未カウント品確認（PWA）

**動作:**
- スキャン画面に「未カウント品を確認」ボタンを追加
- タップ → GAS API呼び出し → 未カウント品の品目ID・品名リストを表示
- モーダルまたは新画面でシンプルなリスト表示
- 「閉じる」でスキャン画面に戻る

**GAS API:**
- 新規: `getUncountedItems` — セッションIDを受け取り、帳簿在庫>0でまだカウントされていない品目一覧を返す
- 戻り値: `[{ 品目ID, 品名, 大カテゴリ }]`

**PWA変更:**
- スキャン画面に「未カウント品を確認」ボタン追加
- 新画面 `screen-st-uncounted` を追加（シンプルなリスト + 閉じるボタン）

### 4. サマリー差異詳細（PWA）

**動作:**
- 棚卸終了前のサマリー画面（screen-st-summary）に差異ありの品目一覧を表示
- 現在の件数表示に加え、差異あり品目の詳細リスト: 品名 / 帳簿 / 実数 / 差異

**GAS API:**
- 既存の `getStocktakeSummary` を拡張
- 戻り値に `details` 配列を追加: 差異あり品目のリスト `[{ 品目ID, 品名, 帳簿在庫, 実数, 差異 }]`

**PWA変更:**
- `fetchStocktakeSummary()` で差異リストをレンダリング
- サマリー画面のHTMLに差異テーブル用の要素を追加

### 5. 棚卸レポート印刷（PC管理画面）

**動作:**
- 棚卸詳細モーダルに「印刷」ボタンを追加
- クリック → 印刷用レイアウトでモーダル内容を印刷
- ヘッダー: セッションID、日時、担当者、ステータス
- テーブル: 品目ID / 品名 / 帳簿在庫 / 実数 / 差異 / 備考
- フッター: 合計カウント数、差異あり数、承認者（確定済みの場合）

**実装:**
- inventory.html: モーダルフッターに印刷ボタン追加
- inventory.css: `@media print` に棚卸モーダル専用スタイル追加（他要素非表示、モーダルのみ表示）
- JavaScriptの追加は不要（window.print()でCSS制御）

## GAS API 変更まとめ

| API | 種類 | 変更内容 |
|-----|------|---------|
| getMyActiveSession | 新規 | gmailで進行中セッション検索、カウント数・全品目数を返す |
| getUncountedItems | 新規 | セッション未カウント品の品目一覧を返す |
| startStocktake | 既存拡張 | 戻り値に totalItems を追加 |
| getStocktakeSummary | 既存拡張 | 戻り値に差異あり品目の details 配列を追加 |

## 検証方法

1. PWA: 棚卸開始 → 数品スキャン → アプリを閉じる → 再度開く → 「再開しますか？」表示 → 再開してスキャン継続
2. PWA: スキャン画面で「5/42品」の進捗表示を確認
3. PWA: 「未カウント品を確認」→ リスト表示 → 閉じてスキャン続行
4. PWA: 棚卸終了 → サマリーに差異あり品目の詳細リスト表示
5. PC: 確定済みセッション詳細モーダル → 「印刷」→ A4印刷プレビュー確認
