# PC在庫管理画面 設計

## 概要

`inventory.html` — PC管理者向けの在庫確認・印刷ページ。
既存スマホPWAとは独立した別ページ。同じ GAS API (config.js + localStorage) を使用。

## 画面構成

3つのタブで切替。フィルタはクライアント側で即時適用。

```
[ヘッダー: タイトル + 印刷ボタン]
[タブ: 現在在庫 | 賞味期限 | 入出庫履歴]
[フィルタ: カテゴリ, 品目名, 期間, 賞味期限○日以内, 場所, データ取得ボタン]
[テーブル: タブに応じた列]
[フッター: 表示件数]
```

## タブ別仕様

| タブ | GAS API | 表示列 | フィルタ項目 |
|------|---------|--------|-------------|
| 現在在庫 | getStockSummary | 品目ID, 品名, カテゴリ, 数量, 単位, 場所 | カテゴリ, 品目名, 場所 |
| 賞味期限 | getLotList | 品目ID, 品名, ロットID, ロット番号, 残数量, 賞味期限, ステータス | 賞味期限○日以内, カテゴリ, 品目名 |
| 入出庫履歴 | getTransactionHistory | 日時, 区分, 品目ID, 品名, 数量, 場所, 担当者 | 期間(from-to), カテゴリ, 品目名, 区分 |

## データ取得フロー

1. タブ切替 or 「データ取得」ボタンで GAS API 呼び出し（初回2-3秒）
2. 取得データをブラウザ側のメモリに保持
3. フィルタ変更時はクライアント側で即時フィルタ（API再呼び出し不要）
4. 「データ取得」ボタンで最新データに再取得

## 印刷

- 「印刷」ボタン → window.print() でブラウザ印刷プレビュー表示
- @media print CSS でフィルタ/ボタン非表示、テーブル全幅
- A4横向き（@page { size: A4 landscape }）
- ページ分割対応（page-break-inside: avoid on tr）
- フィルタ適用後の表示データをそのまま印刷

## ファイル構成

| ファイル | 役割 |
|---------|------|
| inventory.html | PC管理画面HTML（タブ、フィルタ、テーブル） |
| inventory.js | データ取得、フィルタ、タブ切替ロジック |
| inventory.css | PC用スタイル + 印刷用CSS |
| config.js | 既存共有（WEB_APP_URL） |

## API 設定

既存PWAと同じ config.js を読み込み、localStorage の WEB_APP_URL を共有。
設定画面は既存PWA側で行う（inventory.html には設定UIは不要）。

## GAS 側で必要な新規API（別作業）

- getStockSummary — V_現在在庫 相当。品目ごとの現在数量・場所を返す
- getLotList — T_ロット の全有効ロット一覧。品名を結合して返す
- getTransactionHistory — T_入出庫 の履歴。期間パラメータで絞り込み可能

これらが未実装の間、PC画面はデータ取得が空で返る。
